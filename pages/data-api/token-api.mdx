# Token API

The dRPC Token API provides access to token information across supported blockchain networks, including token metadata, supported assets, price symbols, and historical price data.

## Available methods

[Get Supported Tokens](/data-api/token-api/getsupportedtokens) : Retrieves a list of all tokens supported by the Wallet API. \
[Get Token Info By Id](/data-api/token-api/gettokeninfobyid) : Fetches detailed metadata for a specific token by its ID. \
[Get Supported Price Symbols](/data-api/token-api/getsupportedpricesymbols) : Returns the list of price symbols supported for token pricing. \
[Search Historical Prices](/data-api/token-api/searchhistoricalprices) : Searches historical price data for a specified token.

The Token API simplifies access to essential token information, enabling developers to create scalable Web3 applications with accurate asset data and historical market insights.
