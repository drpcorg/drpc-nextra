## Data API Methods

The dRPC [Data API](https://drpc.org/data-api) provides unified access to blockchain data across multiple networks. These endpoints allow retrieving portfolio, balance, transaction, PNL, token, NFT, and protocol data, facilitating efficient wallet tracking and multichain application development.

## Supported chains

Returns the list of blockchain networks supported by the Data API, along with details for a specific chain.

[Get Supported Chains](/data-api/blockchain-api/getsupportedchains) : Retrieves a list of all chains supported by the Data API. \
[Get Supported Chain By Id](/data-api/blockchain-api/getsupportedchainbyid) : Fetches details of a specific supported chain by its ID.

## Portfolio API

Provides portfolio value, net worth history, transaction history, and profit-and-loss data for EVM and non-EVM wallets.

[Get EVM Portfolio](/data-api/portfolio-api/getevmportfolio) : Returns the token portfolio and balances for an EVM-compatible wallet address. \
[Get non-EVM Portfolio](/data-api/portfolio-api/getnonevmportfolio) : Returns the token portfolio and balances for a non-EVM wallet address. \
[Get Historical Net Worth](/data-api/portfolio-api/gethistoricalnetworth) : Retrieves the historical net worth of a wallet over time. \
[Get PNL History](/data-api/portfolio-api/getpnlhistory) : Returns the historical profit and loss (PNL) data for a wallet. \
[Get Aggregated PNL](/data-api/portfolio-api/getaggregatedpnl) : Provides aggregated profit and loss data across a wallet's holdings. \
[Get PnL for Multiple Wallets](/data-api/portfolio-api/getpnlformultiplewallets) : Retrieves profit and loss data for multiple wallet addresses at once. \
[Get Yield Recommendations](/data-api/portfolio-api/getyieldrecommendations) : Returns yield opportunity recommendations based on a wallet's holdings.

## Transactions API

The dRPC Transactions API provides access to wallet transaction history across supported blockchain networks. Retrieve past wallet activity, track on-chain interactions, and display transaction records without building and maintaining your own indexing infrastructure.

[Get Transactions History](/data-api/transaction-api/gettransactionshistory) : Fetches the transaction history for a given wallet address.

## Token API

Supplies information on supported tokens, their metadata, price symbols, and historical price data.

[Get Supported Tokens](/data-api/token-api/getsupportedtokens) : Retrieves a list of all tokens supported by the Data API. \
[Get Token Info By Id](/data-api/token-api/gettokeninfobyid) : Fetches detailed metadata for a specific token by its ID. \
[Get Supported Price Symbols](/data-api/token-api/getsupportedpricesymbols) : Returns the list of price symbols supported for token pricing. \
[Search Historical Prices](/data-api/token-api/searchhistoricalprices) : Searches historical price data for a specified token.

## NFT API

Retrieves NFT holdings, collection data, and metadata for wallets and individual NFTs.

[Get Wallet NFTs (Non-EVM)](/data-api/nft-api/getwalletnfts) : Retrieves the NFTs held by a non-EVM wallet address. \
[Get NFT Collections](/data-api/nft-api/getnftcollections) : Fetches the NFT collections associated with a wallet. \
[Get NFT Metadata by ID](/data-api/nft-api/getnftmetadatabyid) : Returns metadata for a specific NFT by its ID. \
[Refresh NFT Metadata](/data-api/nft-api/refreshnftmetadata) : Triggers a refresh of the stored metadata for a specific NFT.

## Protocols

Provides historical yield data for DeFi protocols.

[Get APR History](/data-api/protocols-api/getaprhistory) : Retrieves the historical annual percentage rate (APR) data for a protocol. \
[Get Ledger Stakes](/data-api/protocols-api/getledgerstakes) : Fetches staking position data for Ledger protocol, including users' staked assets and related information. \
[Get Ledger Grow](/data-api/protocols-api/getledgergrow) : Fetches yield and position data for Ledger Grow, including users' deposited assets and generated rewards.
