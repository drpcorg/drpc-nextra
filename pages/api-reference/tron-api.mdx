# Tron API Overview

Welcome to the Tron API Quickstart and Reference Guide. This guide provides everything you need to start building on Tron using dRPC’s JSON-RPC API. Whether you're retrieving account balances, fetching block details, executing transactions, or estimating gas fees, this comprehensive guide will help you integrate Tron seamlessly into your applications.

This page includes:

- A **Quickstart Guide** to help you set up and make your first Tron API request.
- A detailed list of **all Tron API methods**, categorized for easy reference.

[Scroll to API Methods](#TronAPIMethods)

## Tron API Quickstart

To get started with building on Tron using dRPC's Tron RPC API, follow these steps:

**1. Create a dRPC Account or Use Public Tron RPC endpoints**

By signing up for a free dRPC account, you can access their Premium Tron RPC endpoints.

**Public endpoints:**

HTTPS

```bash
https://tron.drpc.org/
```

**2. Set Up Your Development Environment**

RPC can be requested in [various ways](https://drpc.org/docs/gettingstarted/firstrequest). In this example, we are going to use Node.js. Ensure you have [Node.js](https://nodejs.org/) and npm installed on your system. You can verify their installation by running:

```bash
node -v
npm -v
```

If not installed, download and install them from the [official Node.js website](https://nodejs.org/).

**3. Initialize Your Project**

Create a new directory for your project and initialize it:

```bash
mkdir tron-drpc-quickstart
cd tron-drpc-quickstart
npm init --yes
```

**4. Install Axios**

Axios is a popular HTTP client for making API requests. Install it using npm:

```bash
npm install axios
```

**5. Obtain dRPC Endpoint**

Log in to your dRPC account and navigate to the Tron RPC endpoints section. Copy the HTTPS endpoint URL for the tron Mainnet.

**6. Write Your First Script**

Create an `index.js` file in your project directory and add the following code:

```jsx
const axios = require('axios');

const url = 'https://lb.drpc.org/ogrpc?network=tron&dkey=YOUR_DRPC_API_KEY';

const payload = {
  jsonrpc: '2.0',
  id: 1,
  method: 'eth_blockNumber',
  params: []
};

axios.post(url, payload)
  .then(response => {
    console.log('The latest block number is', parseInt(response.data.result, 16));
  })
  .catch(error => {
    console.error('Error fetching block number:', error);
  });
```

Replace `‘https://lb.drpc.org/ogrpc?network=tron&dkey=YOUR_DRPC_API_KEY'` with the actual endpoint URL you obtained from dRPC.

**7. Run Your Script**

Execute your script using Node.js:

```bash
node index.js
```

You should see the latest Tron block number printed in your console.

**Additional Information**

dRPC offers various features such as high performance nodes, access to multiple chains. For more details, visit their [Tron API documentation](https://developers.tron.network/reference/eth_accounts).

By following these steps, you can start building on Tron using dRPC's reliable and efficient RPC endpoints.

## Tron JSON RPC API Methods

These endpoints allow to retrieve information about blocks, transactions, balances, logs, and more, facilitating efficient blockchain development and integration.

## Accounts info

Retrieves data about an account’s on-chain storage, balance, and contract code.

[eth_accounts](/tron-api/tron-json-rpc-api/accountinfo/eth_accounts) : Retrieves a list of accounts controlled by the client. \
[eth_getBalance](/tron-api/tron-json-rpc-api/accountinfo/eth_getBalance) : Fetches the balance of an account. \
[eth_getCode](/tron-api/tron-json-rpc-api/accountinfo/eth_getCode) : Returns the smart contract code stored at an address. \
[eth_getProof](/tron-api/tron-json-rpc-api/accountinfo/eth_getProof) : Provides a Merkle proof for an account's state. \
[eth_getStorageAt](/tron-api/tron-json-rpc-api/accountinfo/eth_getStorageAt) : Retrieves data stored at a specific storage slot of an account.

## Blocks info

Retrieves detailed information about a specific block using its number or hash

[eth_blockNumber](/tron-api/tron-json-rpc-api/blocksinfo/eth_blockNumber) : Retrieves the most recent block number.  \
[eth_getBlockByHash](/tron-api/tron-json-rpc-api/blocksinfo/eth_getBlockByHash) : Fetches block details by hash.  \
[eth_getBlockByHash#full](/tron-api/tron-json-rpc-api/blocksinfo/eth_getBlockByHashfull) : Returns full block details by hash.  \
[eth_getBlockByNumber](/tron-api/tron-json-rpc-api/blocksinfo/eth_getBlockByNumber) : Retrieves block data by number.  \
[eth_getBlockByNumber#full](/tron-api/tron-json-rpc-api/blocksinfo/eth_getBlockByNumberfull) : Fetches full block details by number. \
[eth_newBlockFilter](/tron-api/tron-json-rpc-api/blocksinfo/eth_newBlockFilter) : Available only on paid tier. Creates a filter for new blocks.  \
[eth_getBlockReceipts](/tron-api/tron-json-rpc-api/blocksinfo/eth_getBlockReceipts) : Fetches receipts for all transactions in a block.  \
[eth_getBlockTransactionCountByHash](/tron-api/tron-json-rpc-api/blocksinfo/eth_getBlockTransactionCountByHash) : Retrieves the number of transactions in a block by its hash.  \
[eth_getBlockTransactionCountByNumber](/tron-api/tron-json-rpc-api/blocksinfo/eth_getBlockTransactionCountByNumber) : Returns the number of transactions in a block by its number.

## Chain info

Gathers essential details about the tron network and its protocol settings.

[eth_chainId](/tron-api/tron-json-rpc-api/chaininfo/eth_chainId) : Retrieves the network's chain ID. \
[eth_protocolVersion](/tron-api/tron-json-rpc-api/chaininfo/eth_protocolVersion) : Returns the protocol version of the client. \
[net_listening](/tron-api/tron-json-rpc-api/chaininfo/net_listening) : Checks if the node is listening for connections. \
[net_version](/tron-api/tron-json-rpc-api/chaininfo/net_version) : Provides the current network version. \
[net_peerCount](/tron-api/tron-json-rpc-api/chaininfo/net_peerCount) : Returns the number of connected peers. \
[eth_syncing](/tron-api/tron-json-rpc-api/chaininfo/eth_syncing) : Indicates whether the node is syncing. \
[eth_hashrate](/tron-api/tron-json-rpc-api/chaininfo/eth_hashrate) : Provides the network's mining hashrate.

## Debug and trace

Available only on paid tier. Contains advanced debugging and tracing tools.

[trace_filter](/tron-api/tron-json-rpc-api/debugandtrace/trace_filter) : Filters trace data based on specific criteria. \
[trace_rawTransaction](/tron-api/tron-json-rpc-api/debugandtrace/trace_rawTransaction) : Replays a raw transaction for debugging. \
[trace_block](/tron-api/tron-json-rpc-api/debugandtrace/trace_block) : Traces all transactions in a block. \
[trace_replayBlockTransactions](/tron-api/tron-json-rpc-api/debugandtrace/trace_replayBlockTransactions) : Replays transactions within a block for analysis. \
[debug_traceBlockByHash](/tron-api/tron-json-rpc-api/debugandtrace/debug_traceBlockByHash) : Traces a block's execution by hash.

## Event logs

Extracts logs related to smart contract events like token transfers or ownership changes.

[eth_getLogs](/tron-api/tron-json-rpc-api/eventlogs/eth_getLogs) : Retrieves logs from the blockchain based on specified filter criteria.  \
[eth_newFilter](/tron-api/tron-json-rpc-api/eventlogs/eth_newFilter) : Available only on paid tier. Creates a new filter to track specific events.  \
[eth_getFilterChanges](/tron-api/tron-json-rpc-api/eventlogs/eth_getFilterChanges) : Available only on paid tier. Retrieves changes for an active filter since its last check. \
[eth_uninstallFilter](/tron-api/tron-json-rpc-api/eventlogs/eth_uninstallFilter) : Removes an installed filter.  \
[eth_getFilterLogs](/tron-api/tron-json-rpc-api/eventlogs/eth_getFilterLogs) : Available only on paid tier. Fetches logs from an active filter.

## Executing transactions

Enables the sending of ETH, contract interaction, or writing data to the chain.

[eth_call](/tron-api/tron-json-rpc-api/executingtransactions/eth_call) : Executes a read-only call to a smart contract without changing the blockchain state. \
[eth_sendRawTransaction](/tron-api/tron-json-rpc-api/executingtransactions/eth_sendRawTransaction) : Broadcasts a raw, signed transaction to the blockchain for execution.

## Gas estimation

Estimates gas prices and consumption for transactions.

[eth_feeHistory](/tron-api/tron-json-rpc-api/gasestimation/eth_feeHistory) : Retrieves historical gas prices over a range of blocks. \
[eth_estimateGas](/tron-api/tron-json-rpc-api/gasestimation/eth_estimateGas) : Estimates the gas required to execute a transaction. \
[eth_gasPrice](/tron-api/tron-json-rpc-api/gasestimation/eth_gasPrice) : Returns the current gas price on the network. \
[eth_createAccessList](/tron-api/tron-json-rpc-api/gasestimation/eth_createAccessList) : Generates an access list for transaction optimization. \
[eth_maxPriorityFeePerGas](/tron-api/tron-json-rpc-api/gasestimation/eth_maxPriorityFeePerGas) : Retrieves the maximum priority fee for gas.

## Getting uncles

Retrieves information about uncle blocks (blocks rejected by the network).

[eth_getUncleByBlockHashAndIndex](/tron-api/tron-json-rpc-api/gettinguncles/eth_getUncleByBlockHashAndIndex) : Fetches details of an uncle block by its hash and index. \
[eth_getUncleByBlockNumberAndIndex](/tron-api/tron-json-rpc-api/gettinguncles/eth_getUncleByBlockNumberAndIndex) : Retrieves an uncle block by its block number and index. \
[eth_getUncleCountByBlockHash](/tron-api/tron-json-rpc-api/gettinguncles/eth_getUncleCountByBlockHash) : Returns the count of uncles for a specific block hash. \
[eth_getUncleCountByBlockNumber](/tron-api/tron-json-rpc-api/gettinguncles/eth_getUncleCountByBlockNumber) : Retrieves the number of uncles for a block number.

## Mining

Consists of methods that provide information related to the mining.

[eth_coinbase](/tron-api/tron-json-rpc-api/mining/eth_coinbase) : Returns the address of the current coinbase (mining reward recipient). \
[eth_mining](/tron-api/tron-json-rpc-api/mining/eth_mining) : Indicates whether the node is currently mining blocks.

## Transactions info

Accesses transaction details, such as their state, count, or receipts.

[eth_getTransactionByHash](/tron-api/tron-json-rpc-api/transactionsinfo/eth_getTransactionByHash) : Fetches transaction details using its hash. \
[eth_getTransactionCount](/tron-api/tron-json-rpc-api/transactionsinfo/eth_getTransactionCount) : Returns the number of transactions sent from an address. \
[eth_getTransactionReceipt](/tron-api/tron-json-rpc-api/transactionsinfo/eth_getTransactionReceipt) : Retrieves the receipt of a processed transaction. \
[eth_newPendingTransactionFilter](/tron-api/tron-json-rpc-api/transactionsinfo/eth_newPendingTransactionFilter) : Available only on paid tier. Sets up a filter to monitor pending transactions. \
[eth_getTransactionByBlockHashAndIndex](/tron-api/tron-json-rpc-api/transactionsinfo/eth_getTransactionByBlockHashAndIndex) : Retrieves a transaction by block hash and index. \
[eth_getTransactionByBlockNumberAndIndex](/tron-api/tron-json-rpc-api/transactionsinfo/eth_getTransactionByBlockNumberAndIndex) : Fetches a transaction by block number and index. \

## Web3

Provides utility functions to interact with the blockchain.

[web3_clientVersion](/tron-api/tron-json-rpc-api/web3/web3_clientVersion) : Returns the version of the client used by the node. \
[web3_sha3](/tron-api/tron-json-rpc-api/web3/web3_sha3) : Computes the Keccak-256 (SHA3) hash of the provided input data.

## Tron HTTP API Methods

## Account info

Returns data about an account's balance, permissions, resources, and multi-signature status on the Tron blockchain.

[getaccount](/tron-api/tron-json-rpc-api/accountinfo/getaccount) : Returns account details such as balance, permissions, and resources for a given address. \
[getaccountnet](/tron-api/tron-json-rpc-api/accountinfo/getaccountnet) : Returns the bandwidth usage and limits for a given account. \
[getaccountresource](/tron-api/tron-json-rpc-api/accountinfo/getaccountresource) : Returns the energy and bandwidth resource usage and limits for a given account. \
[getaccountbalance](/tron-api/tron-json-rpc-api/accountinfo/getaccountbalance) : Returns the TRX balance of an account at a specific block height. \
[createaccount](/tron-api/tron-json-rpc-api/accountinfo/createaccount) : Creates a new account on the Tron network, activated by an existing account. \
[updateaccount](/tron-api/tron-json-rpc-api/accountinfo/updateaccount) : Updates the account name associated with a Tron address. \
[accountpermissionupdate](/tron-api/tron-json-rpc-api/accountinfo/accountpermissionupdate) : Updates the owner, witness, and active permissions of a multi-signature account. \
[validateaddress](/tron-api/tron-json-rpc-api/accountinfo/validateaddress) : Validates whether a given string is a properly formatted Tron address. \
[getapprovedlist](/tron-api/tron-json-rpc-api/accountinfo/getapprovedlist) : Returns the list of approving addresses for a pending multi-signature transaction. \
[getsignweight](/tron-api/tron-json-rpc-api/accountinfo/getsignweight) : Returns the current signature weight and threshold status of a multi-signature transaction.

## Blocks info

Retrieves detailed information from a specified Tron block, including transactions and block header data.

[getnowblock](/tron-api/tron-json-rpc-api/blocksinfo/getnowblock) : Returns the most recent confirmed block on the Tron blockchain. \
[getblock](/tron-api/tron-json-rpc-api/blocksinfo/getblock) : Returns block details by block number, block hash, or the latest block if no parameter is given. \
[getblockbyid](/tron-api/tron-json-rpc-api/blocksinfo/getblockbyid) : Returns block details for a specific block hash (block ID). \
[getblockbylatestnum](/tron-api/tron-json-rpc-api/blocksinfo/getblockbylatestnum) : Returns a list of the most recent blocks up to a specified count. \
[getblockbylimitnext](/tron-api/tron-json-rpc-api/blocksinfo/getblockbylimitnext) : Returns a range of blocks between a start and end block number. \
[getblockbynum](/tron-api/tron-json-rpc-api/blocksinfo/getblockbynum) : Returns block details for a specific block number. \
[getblockbalance](/tron-api/tron-json-rpc-api/blocksinfo/getblockbalance) : Returns the aggregated balance changes for all accounts within a specific block.

## Transactions info

Retrieves data on individual transactions, and creates or broadcasts new ones.

[gettransactionbyid](/tron-api/tron-json-rpc-api/transactionsinfo/gettransactionbyid) : Returns transaction details for a given transaction hash (ID). \
[gettransactioncountbyblocknum](/tron-api/tron-json-rpc-api/transactionsinfo/gettransactioncountbyblocknum) : Returns the number of transactions included in a specific block. \
[gettransactionfrompending](/tron-api/tron-json-rpc-api/transactionsinfo/gettransactionfrompending) : Returns a pending transaction from the node's transaction pool by its hash. \
[gettransactioninfobyblocknum](/tron-api/tron-json-rpc-api/transactionsinfo/gettransactioninfobyblocknum) : Returns execution results and receipts for all transactions in a specific block. \

[gettransactionlistfrompending](/tron-api/tron-json-rpc-api/transactionsinfo/gettransactionlistfrompending) : Returns the list of transaction hashes currently in the node's pending transaction pool. \
[createtransaction](/tron-api/tron-json-rpc-api/transactionsinfo/createtransaction) : Creates an unsigned TRX transfer transaction between two addresses. \
[broadcasttransaction](/tron-api/tron-json-rpc-api/transactionsinfo/broadcasttransaction) : Broadcasts a signed transaction to the Tron network. \
[broadcasthex](/tron-api/tron-json-rpc-api/transactionsinfo/broadcasthex) : Broadcasts a signed transaction supplied as a raw hex string to the Tron network.

[getcontractinfo](/tron-api/tron-http-api/smartcontracts/getcontractinfo) : Returns extended contract information, including ABI and source metadata, by address. \
[clearabi](/tron-api/tron-http-api/smartcontracts/clearabi) : Creates a transaction that clears the stored ABI of a smart contract. \
[estimateenergy](/tron-api/tron-http-api/smartcontracts/estimateenergy) : Estimates the energy required to execute a smart contract call before sending it. \
[updatesetting](/tron-api/tron-http-api/smartcontracts/updatesetting) : Updates the user resource percentage (consume_user_resource_percent) of a smart contract. \
[updateenergylimit](/tron-api/tron-http-api/smartcontracts/updateenergylimit) : Updates the origin energy limit of a deployed smart contract.
