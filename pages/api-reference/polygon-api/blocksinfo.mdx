## Blocks info

Retrieves detailed information from a specified block, including transactions, receipts, and block data.

[eth_blockNumber](/api-reference/polygon-api/blocksinfo/eth_blockNumber) : Fetches the current block number.  \
[eth_getBlockByHash](/api-reference/polygon-api/blocksinfo/eth_getBlockByHash) : Retrieves block details by hash.  \
[eth_getBlockByHash#full](/api-reference/polygon-api/blocksinfo/eth_getBlockByHashfull) : Returns full block details by hash.  \
[eth_getBlockByNumber](/api-reference/polygon-api/blocksinfo/eth_getBlockByNumber) : Fetches block data by block number.  \
[eth_getBlockByNumber#full](/api-reference/polygon-api/blocksinfo/eth_getBlockByNumberfull) : Retrieves full block details by number.  \
[eth_newBlockFilter](/api-reference/polygon-api/blocksinfo/eth_newBlockFilter) : Available only on paid tier. Creates a filter for new blocks.  \
[eth_getBlockReceipts](/api-reference/polygon-api/blocksinfo/eth_getBlockReceipts) : Fetches receipts of all transactions in a block.  \
[eth_getBlockTransactionCountByHash](/api-reference/polygon-api/blocksinfo/eth_getBlockTransactionCountByHash) : Returns the number of transactions in a block by hash.  \
[eth_getBlockTransactionCountByNumber](/api-reference/polygon-api/blocksinfo/eth_getBlockTransactionCountByNumber) : Retrieves the transaction count for a block by number.

These methods provide key tools for analyzing block data on the Polygon network.
