## Send your first request

Each dRPC endpoint includes your key as the `dkey` URL parameter and the target network as `network`. You can also send the key via the `Drpc-Key` header instead.

```bash
curl -X POST 'https://lb.drpc.live/ethereum/YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  --data '{"method":"eth_blockNumber","params":[],"id":1,"jsonrpc":"2.0"}'
```

## Products

[NodeCloud](https://drpc.org/nodecloud-multichain-rpc-management)
Multichain endpoint management: smart routing across 40+ underlying providers, key controls, observability dashboards, and team management.

[Data & Wallet API](https://drpc.org/data-api)
Indexed queries for wallet portfolios, token prices, NFTs, DeFi protocol data, and transaction history — without running your own indexer.

[NodeCore](https://drpc.org/nodecore-open-source-rpc-infrastructure)
Open-source RPC infrastructure stack for teams that want to self-host their own RPC cluster.

[NodeHaus](https://drpc.org/nodehaus-rpc-infrastructure-for-chains)
Managed RPC infrastructure for blockchain foundations, covering public nodes, faucets, and dashboards at the chain level.
