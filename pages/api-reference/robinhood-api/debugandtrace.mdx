# Debug and trace

The Debug and trace group allows to trace transactions, inspect block execution, and replay transactions or blocks for detailed analysis. Key methods include:

[trace_filter](/robinhood-api/debugandtrace/trace_filter) : Filters trace data based on criteria. \
[trace_block](/robinhood-api/debugandtrace/trace_block) : Traces execution of all transactions in a block. \
[trace_replayBlockTransactions](/robinhood-api/debugandtrace/trace_replayBlockTransactions) : Replays block transactions for debugging. \
[debug_traceBlockByHash](/robinhood-api/debugandtrace/debug_traceBlockByHash) : Traces a block by its hash. \
[debug_traceBlockByNumber](/robinhood-api/debugandtrace/debug_traceBlockByNumber) : Traces a block by its number. \
[trace_transaction](/robinhood-api/debugandtrace/trace_transaction) : Traces a specific transaction. \
[debug_traceTransaction](/robinhood-api/debugandtrace/debug_traceTransaction) : Provides detailed trace data for a transaction. \
[trace_replayTransaction](/robinhood-api/debugandtrace/trace_replayTransaction) : Replays a transaction for debugging. \
[trace_get](/robinhood-api/debugandtrace/trace_get) : Retrieves trace data by criteria. \
[trace_call](/robinhood-api/debugandtrace/trace_call) : Executes a trace call. \
[debug_traceCall](/robinhood-api/debugandtrace/debug_traceCall) : Traces a specific call without state change. \
[debug_accountRange](/robinhood-api/debugandtrace/debug_accountRange) : Returns a list of accounts and their state at a given block, used for state inspection. \
[debug_dumpBlock](/robinhood-api/debugandtrace/debug_dumpBlock) : Retrieves the full state of a block as a JSON dump for debugging. \
[debug_getBadBlocks](/robinhood-api/debugandtrace/debug_getBadBlocks) : Returns a list of the most recent "bad" (invalid) blocks the client has encountered. \
[debug_getModifiedAccountsByHash](/robinhood-api/debugandtrace/debug_getModifiedAccountsByHash) : Returns accounts modified between two block hashes. \
[debug_getModifiedAccountsByNumber](/robinhood-api/debugandtrace/debug_getModifiedAccountsByNumber) : Returns accounts modified between two block numbers. \
[debug_getRawBlock](/robinhood-api/debugandtrace/debug_getRawBlock) : Returns the RLP-encoded raw block data. \
[debug_getRawHeader](/robinhood-api/debugandtrace/debug_getRawHeader) : Returns the RLP-encoded raw block header. \
[debug_getRawReceipts](/robinhood-api/debugandtrace/debug_getRawReceipts) : Returns the RLP-encoded raw transaction receipts for a block. \
[debug_getRawTransaction](/robinhood-api/debugandtrace/debug_getRawTransaction) : Returns the RLP-encoded raw transaction data. \
[debug_intermediateRoots](/robinhood-api/debugandtrace/debug_intermediateRoots) : Returns the intermediate state roots produced while executing a block's transactions. \
[debug_storageRangeAt](/robinhood-api/debugandtrace/debug_storageRangeAt) : Returns a range of storage entries for an account at a given block and transaction index. \
[debug_traceBlock](/robinhood-api/debugandtrace/debug_traceBlock) : Traces all transactions in a given RLP-encoded block. \
[debug_traceCallMany](/robinhood-api/debugandtrace/debug_traceCallMany) : Executes and traces multiple call objects against a given block state.

These methods provide developers with essential tools for debug and trace on the Robinhood network.
