# Getting uncles

The Getting uncles group retrieves information about "uncle" blocks, which are valid but not included in the blockchain. Key methods include:

[eth_getUncleByBlockHashAndIndex](/robinhood-api/gettinguncles/eth_getUncleByBlockHashAndIndex) : Retrieves uncle block information by block hash and index. \
[eth_getUncleByBlockNumberAndIndex](/robinhood-api/gettinguncles/eth_getUncleByBlockNumberAndIndex) : Fetches uncle block details by block number and index. \
[eth_getUncleCountByBlockHash](/robinhood-api/gettinguncles/eth_getUncleCountByBlockHash) : Returns the number of uncle blocks for a block hash. \
[eth_getUncleCountByBlockNumber](/robinhood-api/gettinguncles/eth_getUncleCountByBlockNumber) : Returns the number of uncle blocks for a block number.

These methods provide developers with essential tools for getting uncles on the Robinhood network.
