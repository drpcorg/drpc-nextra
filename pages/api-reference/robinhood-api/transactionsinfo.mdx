# Transactions info

The Transactions info group retrieves data on individual transactions, such as status, receipt, and inclusion in a specific block. Key methods include:

[eth_getTransactionByHash](/robinhood-api/transactionsinfo/eth_getTransactionByHash) : Fetches transaction details using its hash. \
[eth_getTransactionCount](/robinhood-api/transactionsinfo/eth_getTransactionCount) : Returns the number of transactions sent from an address. \
[eth_getTransactionReceipt](/robinhood-api/transactionsinfo/eth_getTransactionReceipt) : Retrieves the receipt of a processed transaction. \
[eth_newPendingTransactionFilter](/robinhood-api/transactionsinfo/eth_newPendingTransactionFilter) : Available only on paid tier. Creates a filter for pending transactions. \
[eth_getTransactionByBlockHashAndIndex](/robinhood-api/transactionsinfo/eth_getTransactionByBlockHashAndIndex) : Retrieves a transaction by block hash and index. \
[eth_getTransactionByBlockNumberAndIndex](/robinhood-api/transactionsinfo/eth_getTransactionByBlockNumberAndIndex) : Retrieves a transaction by block number and index. \
[txpool_content](/robinhood-api/transactionsinfo/txpool_content) : Provides details of the transaction pool content. \
[eth_getRawTransactionByBlockHashAndIndex](/robinhood-api/transactionsinfo/eth_getRawTransactionByBlockHashAndIndex) : Returns the raw (RLP-encoded) transaction at a given block hash and index. \
[eth_getRawTransactionByHash](/robinhood-api/transactionsinfo/eth_getRawTransactionByHash) : Returns the raw (RLP-encoded) transaction data for a given transaction hash.

These methods provide developers with essential tools for transactions info on the Robinhood network.
