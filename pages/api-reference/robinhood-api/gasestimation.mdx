# Gas estimation

The Gas estimation group estimates gas fees for transactions and provides historical and current gas price data. Key methods include:

[eth_feeHistory](/robinhood-api/gasestimation/eth_feeHistory) : Retrieves historical gas fees over a specified range of blocks. \
[eth_estimateGas](/robinhood-api/gasestimation/eth_estimateGas) : Estimates the gas required for a transaction based on its parameters. \
[eth_gasPrice](/robinhood-api/gasestimation/eth_gasPrice) : Returns the current gas price. \
[eth_createAccessList](/robinhood-api/gasestimation/eth_createAccessList) : Generates an access list to reduce gas costs. \
[eth_maxPriorityFeePerGas](/robinhood-api/gasestimation/eth_maxPriorityFeePerGas) : Retrieves the maximum priority fee per gas unit. \
[eth_blobBaseFee](/robinhood-api/gasestimation/eth_blobBaseFee) : Returns the base fee per blob gas for the current or next block (EIP-4844).

These methods provide developers with essential tools for gas estimation on the Robinhood network.
