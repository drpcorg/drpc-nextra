## Transactions info

Retrieves data on individual transactions, such as status, receipt, and inclusion in a specific block.

[eth_getTransactionByHash](/api-reference/ethereum-api/transactionsinfo/eth_getTransactionByHash) : Fetches transaction details using its hash.  \
[eth_getTransactionCount](/api-reference/ethereum-api/transactionsinfo/eth_getTransactionCount) : Returns the number of transactions sent from an address. \
[eth_getTransactionReceipt](/api-reference/ethereum-api/transactionsinfo/eth_getTransactionReceipt) : Retrieves the receipt of a processed transaction.  \
[eth_newPendingTransactionFilter](/api-reference/ethereum-api/transactionsinfo/eth_newPendingTransactionFilter) : Available only on paid tier. Sets up a filter for monitoring pending transactions. \
[eth_getTransactionByBlockHashAndIndex](/api-reference/ethereum-api/transactionsinfo/eth_getTransactionByBlockHashAndIndex) : Fetches a transaction by block hash and index. \
[eth_getTransactionByBlockNumberAndIndex](/api-reference/ethereum-api/transactionsinfo/eth_getTransactionByBlockNumberAndIndex) : Retrieves a transaction by block number and index. \
[txpool_content](/api-reference/ethereum-api/transactionsinfo/txpool_content) : Provides the contents of the transaction pool.

These methods assist in transaction tracking and management on Ethereum.
