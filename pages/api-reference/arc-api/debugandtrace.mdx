# Debug and trace

The Debug and trace group allows to trace transactions, inspect block execution, and replay transactions or blocks for detailed analysis. Key methods include:

[trace_filter](/api-reference/arc-api/debugandtrace/trace_filter) : Filters trace data based on criteria. \
[trace_rawTransaction](/api-reference/arc-api/debugandtrace/trace_rawTransaction) : Replays a raw transaction for debugging. \
[trace_block](/api-reference/arc-api/debugandtrace/trace_block) : Traces execution of all transactions in a block. \
[trace_replayBlockTransactions](/api-reference/arc-api/debugandtrace/trace_replayBlockTransactions) : Replays block transactions for debugging. \
[debug_traceBlockByHash](/api-reference/arc-api/debugandtrace/debug_traceBlockByHash) : Traces a block by its hash. \
[debug_traceBlockByNumber](/api-reference/arc-api/debugandtrace/debug_traceBlockByNumber) : Traces a block by its number. \
[trace_transaction](/api-reference/arc-api/debugandtrace/trace_transaction) : Traces a specific transaction. \
[debug_traceTransaction](/api-reference/arc-api/debugandtrace/debug_traceTransaction) : Provides detailed trace data for a transaction. \
[trace_replayTransaction](/api-reference/arc-api/debugandtrace/trace_replayTransaction) : Replays a transaction for debugging. \
[trace_callMany](/api-reference/arc-api/debugandtrace/trace_callMany) : Executes multiple trace calls. \
[trace_get](/api-reference/arc-api/debugandtrace/trace_get) : Retrieves trace data by criteria. \
[trace_call](/api-reference/arc-api/debugandtrace/trace_call) : Executes a trace call. \
[debug_traceCall](/api-reference/arc-api/debugandtrace/debug_traceCall) : Traces a specific call without state change. \
[debug_storageRangeAt](/api-reference/arc-api/debugandtrace/debug_storageRangeAt) : Returns the contract storage for a specified range. \
[debug_traceBlock](/api-reference/arc-api/debugandtrace/debug_traceBlock) : Traces the execution of all transactions in a supplied raw block. \
[debug_traceCallMany](/api-reference/arc-api/debugandtrace/debug_traceCallMany) : Executes and traces multiple call bundles in sequence.

These methods provide developers with essential tools for debug and trace on the Arc network.
