# Mining

The Mining group provides details on the mining state of the node. Key methods include:

[eth_coinbase](/arc-api/mining/eth_coinbase) : Returns the address of the miner who is receiving mining rewards. \
[eth_mining](/arc-api/mining/eth_mining) : Indicates whether the node is actively mining blocks.

These methods provide developers with essential tools for mining on the Arc network.
