# Subscriptions

The Subscriptions group allows to subscribe to specific events in real-time via WebSockets. Key methods include:

[eth_subscribe](/arc-api/subscriptions/eth_subscribe) : Subscribes to various blockchain events such as new blocks, pending transactions, or logs. \
[eth_unsubscribe](/arc-api/subscriptions/eth_unsubscribe) : Unsubscribes from an existing event subscription.

These methods provide developers with essential tools for subscriptions on the Arc network.
