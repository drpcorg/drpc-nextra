## Debug and trace

Offers advanced debugging and tracing capabilities.

[debug_traceBlockByHash](/api-reference/mantle-api/debugandtrace/debug_traceBlockByHash) : Traces the execution of a block by its hash. \
[debug_traceBlockByNumber](/api-reference/mantle-api/debugandtrace/debug_traceBlockByNumber) : Traces the execution of a block by its number. \
[debug_traceTransaction](/api-reference/mantle-api/debugandtrace/debug_traceTransaction) : Provides detailed trace information for a specific transaction.

These methods help developers analyze transaction execution and block behavior on the Mantle network.
