## Gas estimation

Estimates gas fees for transactions and provides historical and current gas price data.

[eth_feeHistory](/api-reference/arbitrum-api/gasestimation/eth_feeHistory) : Retrieves historical gas fees over a specified range of blocks. \
[eth_estimateGas](/api-reference/arbitrum-api/gasestimation/eth_estimateGas) : Estimates the gas required for a transaction based on its parameters. \
[eth_gasPrice](/api-reference/arbitrum-api/gasestimation/eth_gasPrice) : Returns the current gas price. \
[eth_createAccessList](/api-reference/arbitrum-api/gasestimation/eth_createAccessList) : Generates an access list to reduce gas costs. \
[eth_maxPriorityFeePerGas](/api-reference/arbitrum-api/gasestimation/eth_maxPriorityFeePerGas) : Retrieves the maximum priority fee per gas unit.

These methods are crucial for optimizing transaction costs on Arbitrum.
