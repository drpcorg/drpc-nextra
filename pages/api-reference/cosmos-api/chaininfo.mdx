## Chain info

Allows gathering detailed information about the current state and configuration of the blockchain.

[abci_info](/api-reference/cosmos-api/chaininfo/abci_info) : Provides information about the ABCI application state. \
[abci_query](/api-reference/cosmos-api/chaininfo/abci_query) : Queries the application for state information. \
[genesis_chunked](/api-reference/cosmos-api/chaininfo/genesis_chunked) : Retrieves the genesis file in chunks. \
[health](/api-reference/cosmos-api/chaininfo/health) : Checks the health of the node. \
[lag_status](/api-reference/cosmos-api/chaininfo/lag_status) : Displays the lag status of the node. \
[status](/api-reference/cosmos-api/chaininfo/status) : Fetches the current status of the node.

These methods are essential for monitoring and managing the Cosmos blockchain.
