## Transactions info

Fetches details about individual transactions, including status, receipts, and block inclusion.

[eth_getTransactionByHash](/api-reference/sonic-api/transactionsinfo/eth_getTransactionByHash): Retrieves a transaction using its hash. \
[eth_getTransactionCount](/api-reference/sonic-api/transactionsinfo/eth_getTransactionCount): Returns the number of transactions sent from an address. \
[eth_getTransactionReceipt](/api-reference/sonic-api/transactionsinfo/eth_getTransactionReceipt): Fetches the receipt of a transaction, including execution status. \
[eth_newPendingTransactionFilter](/api-reference/sonic-api/transactionsinfo/eth_newPendingTransactionFilter): Creates a filter to track pending transactions. \
[eth_getTransactionByBlockHashAndIndex](/api-reference/sonic-api/transactionsinfo/eth_getTransactionByBlockHashAndIndex): Retrieves a transaction from a block using its hash and index. \
[eth_getTransactionByBlockNumberAndIndex](/api-reference/sonic-api/transactionsinfo/eth_getTransactionByBlockNumberAndIndex): Fetches a transaction by block number and index. \
[txpool_content](/api-reference/sonic-api/transactionsinfo/txpool_content): Provides details of pending transactions in the transaction pool.

These methods are essential for tracking and managing transactions on the Sonic network.
