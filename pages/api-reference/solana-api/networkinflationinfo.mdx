## Network inflation info

Solana implements a staking and inflation model to incentivize validators and participants. These methods help retrieve inflation-related data.

[getInflationGovernor](/api-reference/solana-api/networkinflationinfo/getInflationGovernor) : Retrieves the inflation governor for the network. \
[getInflationRate](/api-reference/solana-api/networkinflationinfo/getInflationRate) : Returns the current inflation rate. \
[getInflationReward](/api-reference/solana-api/networkinflationinfo/getInflationReward) : Provides the inflation reward amount for validators. \
[getSupply](/api-reference/solana-api/networkinflationinfo/getSupply) : Retrieves the total supply of tokens in the network.

These methods are crucial for understanding the inflation dynamics within the Solana ecosystem.
