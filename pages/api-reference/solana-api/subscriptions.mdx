## Subscriptions

Allows clients to receive real-time updates and notifications about various on-chain events.

[accountSubscribe](/api-reference/solana-api/subscriptions/accountSubscribe) : Subscribes to account updates. \
[accountUnsubscribe](/api-reference/solana-api/subscriptions/accountUnsubscribe) : Unsubscribes from account updates. \
[blockSubscribe](/api-reference/solana-api/subscriptions/blockSubscribe) : Subscribes to block updates. \
[blockUnsubscribe](/api-reference/solana-api/subscriptions/blockUnsubscribe) : Unsubscribes from block updates. \
[logsSubscribe](/api-reference/solana-api/subscriptions/logsSubscribe) : Subscribes to log updates. \
[logUnsubscribe](/api-reference/solana-api/subscriptions/logUnsubscribe) : Unsubscribes from log updates. \
[programSubscribe](/api-reference/solana-api/subscriptions/programSubscribe) : Subscribes to program updates. \
[programUnsubscribe](/api-reference/solana-api/subscriptions/programUnsubscribe) : Unsubscribes from program updates. \
[signatureSubscribe](/api-reference/solana-api/subscriptions/signatureSubscribe) : Subscribes to signature updates. \
[signatureUnsubscribe](/api-reference/solana-api/subscriptions/signatureUnsubscribe) : Unsubscribes from signature updates. \
[slotSubscribe](/api-reference/solana-api/subscriptions/slotSubscribe) : Subscribes to slot updates. \
[slotUnsubscribe](/api-reference/solana-api/subscriptions/slotUnsubscribe) : Unsubscribes from slot updates.

These methods enable real-time monitoring of important events on the Solana network.
