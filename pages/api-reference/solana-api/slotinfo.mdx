## Slot info

Slots represent periods of time during which a leader is responsible for processing transactions. These methods provide data related to slot timing and leadership.

[getMaxRetransmitSlot](/api-reference/solana-api/slotinfo/getMaxRetransmitSlot) : Retrieves the maximum slot for retransmission. \
[getMaxShredInsertSlot](/api-reference/solana-api/slotinfo/getMaxShredInsertSlot) : Provides the maximum slot for shred insertion. \
[getSlot](/api-reference/solana-api/slotinfo/getSlot) : Returns the current slot. \
[getSlotLeader](/api-reference/solana-api/slotinfo/getSlotLeader) : Fetches the leader for the current slot. \
[getSlotLeaders](/api-reference/solana-api/slotinfo/getSlotLeaders) : Lists leaders for upcoming slots. \
[minimumLedgerSlot](/api-reference/solana-api/slotinfo/minimumLedgerSlot) : Retrieves the minimum ledger slot. \
[getLeaderSchedule](/api-reference/solana-api/slotinfo/getLeaderSchedule) : Provides the schedule of slot leaders.

These methods help monitor and analyze slot-related data on the Solana network.
