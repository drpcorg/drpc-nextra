## Token info

Focuses on accounts and balances associated with specific tokens.

[getTokenSupply](/api-reference/solana-api/tokeninfo/getTokenSupply) : Retrieves the total supply of a specific token. \
[getTokenAccountBalance](/api-reference/solana-api/tokeninfo/getTokenAccountBalance) : Returns the balance of a specific token account. \
[getTokenAccountsByDelegate](/api-reference/solana-api/tokeninfo/getTokenAccountsByDelegate) : Lists token accounts associated with a delegate. \
[getTokenAccountsByOwner](/api-reference/solana-api/tokeninfo/getTokenAccountsByOwner) : Fetches token accounts owned by a specific address. \
[getTokenLargestAccounts](/api-reference/solana-api/tokeninfo/getTokenLargestAccounts) : Provides a list of the largest token accounts. \
[requestAirdrop](/api-reference/solana-api/tokeninfo/requestAirdrop) : Requests an airdrop of tokens to a specified account.

These methods are essential for managing token-related operations on the Solana network.
