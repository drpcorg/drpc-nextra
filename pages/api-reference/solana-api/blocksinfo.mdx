## Blocks info

Provides detailed insights about blocks on the blockchain.

[getBlockCommitment](/api-reference/solana-api/blocksinfo/getBlockCommitment) : Fetches the commitment level of a block. \
[getBlockProduction](/api-reference/solana-api/blocksinfo/getBlockProduction) : Provides information on block production rates. \
[getBlocks](/api-reference/solana-api/blocksinfo/getBlocks) : Lists blocks based on specified criteria. \
[getBlock](/api-reference/solana-api/blocksinfo/getBlock) : Retrieves details of a specific block. \
[getBlocksWithLimit](/api-reference/solana-api/blocksinfo/getBlocksWithLimit) : Fetches a limited number of blocks. \
[getBlockHeight](/api-reference/solana-api/blocksinfo/getBlockHeight) : Returns the height of a specific block. \
[getBlockTime](/api-reference/solana-api/blocksinfo/getBlockTime) : Provides the timestamp for a block. \
[getConfirmedBlocks](/api-reference/solana-api/blocksinfo/getConfirmedBlocks) : Lists confirmed blocks in the chain. \
[getConfirmedBlock](/api-reference/solana-api/blocksinfo/getConfirmedBlock) : Retrieves a confirmed block's details. \
[isBlockhashValid](/api-reference/solana-api/blocksinfo/isBlockhashValid) : Checks if a blockhash is valid. \
[getLatestBlockhash](/api-reference/solana-api/blocksinfo/getLatestBlockhash) : Returns the latest blockhash.

These methods provide essential insights for analyzing blockchain data on the Solana network.
