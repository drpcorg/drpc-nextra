## Network info

Offers aggregate data related to the overall network status and operational metrics.

[getEpochInfo](/api-reference/solana-api/networkinfo/getEpochInfo) : Retrieves information about the current epoch. \
[getEpochSchedule](/api-reference/solana-api/networkinfo/getEpochSchedule) : Provides the schedule for the current epoch. \
[getFeeForMessage](/api-reference/solana-api/networkinfo/getFeeForMessage) : Returns the fee for processing a specific message. \
[getHighestSnapshotSlot](/api-reference/solana-api/networkinfo/getHighestSnapshotSlot) : Fetches the highest snapshot slot in the network. \
[getGenesisHash](/api-reference/solana-api/networkinfo/getGenesisHash) : Retrieves the hash of the genesis block. \
[getRecentPerformanceSamples](/api-reference/solana-api/networkinfo/getRecentPerformanceSamples) : Provides recent performance metrics for the network. \
[getFirstAvailableBlock](/api-reference/solana-api/networkinfo/getFirstAvailableBlock) : Returns the first available block in the chain. \
[getMinimumBalanceForRentExemption](/api-reference/solana-api/networkinfo/getMinimumBalanceForRentExemption) : Fetches the minimum balance required for rent exemption. \
[getFees](/api-reference/solana-api/networkinfo/getFees) : Returns the current fee structure for transactions. \
[getFeeCalculatorForBlockhash](/api-reference/solana-api/networkinfo/getFeeCalculatorForBlockhash) : Provides the fee calculator for a specific blockhash. \
[getRecentPrioritizationFees](/api-reference/solana-api/networkinfo/getRecentPrioritizationFees) : Retrieves recent prioritization fees for transactions.

These methods are essential for monitoring the operational status of the Solana network.
