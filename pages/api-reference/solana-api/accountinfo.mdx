## Accounts info

Offers detailed information regarding the on-chain state of accounts.

[getAccountInfo](/api-reference/solana-api/accountinfo/getAccountInfo) : Retrieves the account's data and lamports. \
[getBalance](/api-reference/solana-api/accountinfo/getBalance) : Returns the balance of the specified account. \
[getVoteAccounts](/api-reference/solana-api/accountinfo/getVoteAccounts) : Fetches vote accounts for the current epoch. \
[getLargestAccounts](/api-reference/solana-api/accountinfo/getLargestAccounts) : Lists the largest accounts by balance. \
[getMultipleAccounts](/api-reference/solana-api/accountinfo/getMultipleAccounts) : Retrieves data for multiple accounts at once. \
[getProgramAccounts](/api-reference/solana-api/accountinfo/getProgramAccounts) : Returns accounts associated with a specific program. \
[getStakeActivation](/api-reference/solana-api/accountinfo/getStakeActivation) : Provides activation status of a stake account.

These methods are essential for managing and monitoring account data on the Solana network.
