## Getting uncles

Retrieves information about "uncle" blocks, which are valid blocks not included in the main blockchain.

[eth_getUncleByBlockHashAndIndex](/api-reference/fantom-api/gettinguncles/eth_getUncleByBlockHashAndIndex) : Obtains details of an uncle block using the parent block's hash and the uncle's index. \
[eth_getUncleByBlockNumberAndIndex](/api-reference/fantom-api/gettinguncles/eth_getUncleByBlockNumberAndIndex) : Fetches information of an uncle block based on the parent block's number and the uncle's index. \
[eth_getUncleCountByBlockHash](/api-reference/fantom-api/gettinguncles/eth_getUncleCountByBlockHash) : Returns the total number of uncle blocks associated with a specific block hash. \
[eth_getUncleCountByBlockNumber](/api-reference/fantom-api/gettinguncles/eth_getUncleCountByBlockNumber) : Retrieves the count of uncle blocks for a block identified by its number.

These endpoints are essential for analyzing uncle blocks within the Fantom network.
