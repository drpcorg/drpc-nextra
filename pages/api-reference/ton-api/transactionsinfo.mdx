## Transactions Info

Provides data about specific transactions, transaction history, and related transaction operations.

[getTransactions](/api-reference/ton-api/transactionsinfo/getBlockTransactions): Fetches transaction history for a specified address. \
[getBlockTransactions](/api-reference/ton-api/transactionsinfo/getBlockTransactions): Retrieves transactions within a specified block. \
[getBlockTransactionsExt](/api-reference/ton-api/transactionsinfo/getBlockTransactionsExt): Offers extended details about all transactions within a block. \
[tryLocateTx](/api-reference/ton-api/transactionsinfo/tryLocateTx): Searches for a specific transaction across multiple blocks. \
[tryLocateResultTx](/api-reference/ton-api/transactionsinfo/tryLocateResultTx): Locates the result of a transaction within the blockchain, \
[tryLocateSourceTx](/api-reference/ton-api/transactionsinfo/tryLocateSourceTx): Searches for the originating source of a transaction. \
[transactions](/api-reference/ton-api/transactionsinfo/transactions): Retrieves a list of transactions. \
[transactionsByMessage](/api-reference/ton-api/transactionsinfo/transactionsByMessage): Fetches transactions associated with a specific message. \
[transactionsByMasterchainBlock](/api-reference/ton-api/transactionsinfo/transactionsByMasterchainBlock): Retrieves all transactions contained within a specified masterchain block \
[adjacentTransactions](/api-reference/ton-api/transactionsinfo/adjacentTransactions): Retrieves transactions that are adjacent to a specified transaction

Transaction methods facilitate tracking and locating specific transactions, making it easier to audit transaction history and verify transaction details across the blockchain.
