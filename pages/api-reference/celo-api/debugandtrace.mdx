## Debug and trace

Available only on the paid tier. Allows tracing transactions, inspecting block execution, and replaying transactions or blocks for detailed analysis.

[trace_filter](/api-reference/celo-api/debugandtrace/trace_filter) : Filters trace data based on criteria. \
[trace_block](/api-reference/celo-api/debugandtrace/trace_block) : Traces execution of all transactions in a block. \
[trace_replayBlockTransactions](/api-reference/celo-api/debugandtrace/trace_replayBlockTransactions) : Replays block transactions for debugging. \
[trace_replayBlockTransactions#vmTrace](/api-reference/celo-api/debugandtrace/trace_replayBlockTransactionsvmTrace) : Provides VM-level trace during block replay. \
[debug_traceBlockByHash](/api-reference/celo-api/debugandtrace/debug_traceBlockByHash) : Traces a block by its hash. \
[debug_traceBlockByNumber](/api-reference/celo-api/debugandtrace/debug_traceBlockByNumber) : Traces a block by its number. \
[trace_transaction](/api-reference/celo-api/debugandtrace/trace_transaction) : Traces a specific transaction. \
[debug_traceTransaction](/api-reference/celo-api/debugandtrace/debug_traceTransaction) : Provides detailed trace data for a transaction. \
[trace_replayTransaction](/api-reference/celo-api/debugandtrace/trace_replayTransaction) : Replays a transaction for debugging. \
[trace_replayTransaction#vmTrace](/api-reference/celo-api/debugandtrace/trace_replayTransactionvmTrace) : Provides VM-level trace during transaction replay. \
[trace_callMany](/api-reference/celo-api/debugandtrace/trace_callMany) : Executes multiple trace calls. \
[trace_get](/api-reference/celo-api/debugandtrace/trace_get) : Retrieves trace data by criteria. \
[trace_call](/api-reference/celo-api/debugandtrace/trace_call) : Executes a trace call. \
[debug_traceCall](/api-reference/celo-api/debugandtrace/debug_traceCall) : Traces a specific call without state change.

These methods provide advanced debugging capabilities, enabling developers to trace execution flows, analyze failed transactions, and inspect block behavior on the Celo network.
