## Chain info

Provides information about the BSC network, including its protocol version, configuration, and current status.

[eth_chainId](/api-reference/bsc-api/chaininfo/eth_chainId) : Returns the chain ID of the network. \
[eth_protocolVersion](/api-reference/bsc-api/chaininfo/eth_protocolVersion) : Provides the protocol version in use by the client. \
[net_listening](/api-reference/bsc-api/chaininfo/net_listening) : Checks if the client is listening for network connections. \
[net_version](/api-reference/bsc-api/chaininfo/net_version) : Retrieves the current network version. \
[net_peerCount](/api-reference/bsc-api/chaininfo/net_peerCount) : Returns the number of active peers connected to the node. \
[eth_syncing](/api-reference/bsc-api/chaininfo/eth_syncing) : Indicates whether the node is synchronizing with the network. \
[eth_hashrate](/api-reference/bsc-api/chaininfo/eth_hashrate) : Provides the node's current mining hashrate.

These methods help monitor the health, configuration, and performance of the network.
