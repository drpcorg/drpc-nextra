## Event logs

Monitors logs from smart contracts, making it useful for tracking events and state changes.

[eth_getLogs](/api-reference/soneium-api/eventlogs/eth_getLogs): Fetches logs matching a given filter. \
[eth_newFilter](/api-reference/soneium-api/eventlogs/eth_newFilter): Establishes a filter to track contract events. \
[eth_getFilterChanges](/api-reference/soneium-api/eventlogs/eth_getFilterChanges): Returns new logs detected since the last check. \
[eth_uninstallFilter](/api-reference/soneium-api/eventlogs/eth_uninstallFilter): Removes an event filter. \
[eth_getFilterLogs](/api-reference/soneium-api/eventlogs/eth_getFilterLogs): Retrieves logs matching a specified filter. \
