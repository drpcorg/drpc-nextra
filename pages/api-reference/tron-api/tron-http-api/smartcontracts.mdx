# Tron Smart contracts

Deploys, calls, and inspects smart contracts on the Tron Virtual Machine (TVM).

[deploycontract](/tron-api/tron-http-api/smartcontracts/deploycontract) : Creates an unsigned transaction to deploy a smart contract to the Tron network.  \
[triggersmartcontract](/tron-api/tron-http-api/smartcontracts/triggersmartcontract) : Creates an unsigned transaction that calls a function on a deployed smart contract. \
[triggerconstantcontract](/tron-api/tron-http-api/smartcontracts/triggerconstantcontract) : Executes a read-only smart contract call without broadcasting a transaction or consuming energy. \
[getcontract](/tron-api/tron-http-api/smartcontracts/getcontract) : Returns the bytecode and metadata of a deployed smart contract by address.  \
[getcontractinfo](/tron-api/tron-http-api/smartcontracts/getcontractinfo) : Returns extended contract information, including ABI and source metadata, by address.  \
[clearabi](/tron-api/tron-http-api/smartcontracts/clearabi) : Creates a transaction that clears the stored ABI of a smart contract.  \
[estimateenergy](/tron-api/tron-http-api/smartcontracts/estimateenergy) : Estimates the energy required to execute a smart contract call before sending it.  \
[updatesetting](/tron-api/tron-http-api/smartcontracts/updatesetting) : Updates the user resource percentage (consume_user_resource_percent) of a smart contract.  \
[updateenergylimit](/tron-api/tron-http-api/smartcontracts/updateenergylimit) : Updates the origin energy limit of a deployed smart contract.
