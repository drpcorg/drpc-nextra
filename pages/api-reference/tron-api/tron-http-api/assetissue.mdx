# Tron Asset issue (TRC10)

Issues, queries, and transfers native TRC10 tokens.

[createassetissue](/api-reference/tron-api/tron-http-api/assetissue/createassetissue) : Issues a new TRC10 token on the Tron network.  \
[getassetissuebyaccount](/api-reference/tron-api/tron-http-api/assetissue/getassetissuebyaccount) : Returns the TRC10 token issued by a specific account.  \
[getassetissuebyid](/api-reference/tron-api/tron-http-api/assetissue/getassetissuebyid) : Returns TRC10 token details by its numeric asset ID.  \
[getassetissuebyname](/api-reference/tron-api/tron-http-api/assetissue/getassetissuebyname) : Returns TRC10 token details by its token name.  \
[getassetissuelist](/api-reference/tron-api/tron-http-api/assetissue/getassetissuelist) : Returns the full list of TRC10 tokens issued on the network.  \
[getassetissuelistbyname](/api-reference/tron-api/tron-http-api/assetissue/getassetissuelistbyname) : Returns all TRC10 tokens that share a given token name.  \
[getpaginatedassetissuelist](/api-reference/tron-api/tron-http-api/assetissue/getpaginatedassetissuelist) : Returns a paginated list of TRC10 tokens using offset and limit parameters.  \
[participateassetissue](/api-reference/tron-api/tron-http-api/assetissue/participateassetissue) : Creates a transaction to purchase a TRC10 token during its issuance period.  \
[transferasset](/api-reference/tron-api/tron-http-api/assetissue/transferasset) : Creates a transaction to transfer a TRC10 token between two addresses.  \
[unfreezeasset](/api-reference/tron-api/tron-http-api/assetissue/unfreezeasset) : Creates a transaction to unfreeze TRX that was frozen for TRC10 issuance bandwidth.  \
[updateasset](/api-reference/tron-api/tron-http-api/assetissue/updateasset) : Updates the description, URL, and limits of an issued TRC10 token.
