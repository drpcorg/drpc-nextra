# Tron Witnesses and voting

Manages Super Representative (witness) registration, voting, and reward distribution.

[createwitness](/api-reference/tron-api/tron-http-api/witnessesandvoting/createwitness) : Creates a transaction to register an account as a Super Representative (witness) candidate.  \
[updatewitness](/api-reference/tron-api/tron-http-api/witnessesandvoting/updatewitness) : Updates the URL associated with a registered witness account.  \
[votewitnessaccount](/api-reference/tron-api/tron-http-api/witnessesandvoting/votewitnessaccount) : Creates a transaction to cast votes for one or more Super Representative candidates.  \
[listwitnesses](/api-reference/tron-api/tron-http-api/witnessesandvoting/listwitnesses) : Returns the full list of Super Representatives and candidates with their vote counts.  \
[getpaginatednowwitnesslist](/api-reference/tron-api/tron-http-api/witnessesandvoting/getpaginatednowwitnesslist) : Returns a paginated list of current Super Representatives using offset and limit parameters.  \
[getBrokerage](/api-reference/tron-api/tron-http-api/witnessesandvoting/getBrokerage) : Returns the brokerage (commission) ratio a witness keeps from voting rewards.  \
[getReward](/api-reference/tron-api/tron-http-api/witnessesandvoting/getReward) : Returns the unwithdrawn voting reward balance for an account.  \
[updateBrokerage](/api-reference/tron-api/tron-http-api/witnessesandvoting/updateBrokerage) : Creates a transaction to update the brokerage ratio a witness keeps from voting rewards.
